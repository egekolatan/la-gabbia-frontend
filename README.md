# La Gabbia - Ristorante Italiano (Frontend)

Fine dining İtalyan restoranı **La Gabbia** için React (Vite) ile geliştirilmiş şık, minimalist ve beyaz temalı web sitesi arayüzü.

## 🚀 Teknolojiler
- React (Vite)
- Lucide React Icons
- Vanilla CSS & Modern Typography (Shadows Into Light, Indie Flower)

## 📦 Kurulum & Çalıştırma
```bash
npm install
npm run dev
```

## 🌐 Canlı Yayın (Vercel)
Proje Vercel ile doğrudan dağıtıma hazırdır.
